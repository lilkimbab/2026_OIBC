# 2026 POSTECH OIBC Big Data Challenge

제6회 POSTECH·KAIST·UNIST AI & 데이터사이언스 경진대회 × 2026 POSTECH OIBC Big Data Challenge에 4명이 한 팀(스타벅스 전기도둑들)으로 참가했다. 태양광 발전소 253곳의 다음 날 발전량을 시간마다 맞히는 대회였고, 10월 초부터 11월 13일 마감까지 6주 정도 붙잡고 있었다.

코드는 정리해서 추후에 이 저장소에 올릴 예정이다.

## 대회

| | |
|---|---|
| 문제 | 발전소 253곳을 두 묶음으로 나누고, 묶음마다 다음 날 시간별 발전량 합계를 예측 |
| 점수 | 전력시장 정산 방식. 예측이 실제와 어긋난 만큼 정산금이 깎인다 |
| 평가 기간 | 2025년 6월 ~ 2026년 5월 (8,760시간 × 2묶음) |
| 제출 | 하루 3번, 전체 20번 |
| 주어진 자료 | 발전소 정보, 학습 기간 발전량과 관측 날씨, 예보사 두 곳(A·B)의 날씨 예보, 전력 가격 |

최종 점수는 **6,481,549,753원**.

## 내가 한 것

모델 쪽에서는 기초 모델을 발전시키고, 모델 9개를 하루 총량과 시간 패턴으로 나눠 섞는 앙상블을 만들었다. 그 위에 공개 기상 모델 예보를 받아서 모델에 붙이는 일, 마지막에 여러 예측을 합치고 보정하는 부분도 맡았다. 제출 파일 관리와, 마감 뒤에 빈 환경에서 결과를 처음부터 다시 만들어 보는 재현 확인도 내가 했다.

## 어떻게 풀었나

```
데이터 → 묶음 나누기 → 모델 9개 → 앙상블 → 기상 모델 3종 결합 → 후처리
```

**데이터.** 대회가 준 예보는 관측 지점 하나하나의 값이라 구름이 어디에 얼마나 퍼져 있는지는 알 수 없다. 그래서 공개된 기상 모델 예보(기상청 UM, 미국 GFS·GEFS, 유럽 CAMS)를 한반도 6×6 칸으로 잘라 입력에 넣었다. 팀에서는 '구름 지도'라고 불렀다. 기상청 UM 칸만 넣어도 발전소별 모델의 검증 오차가 3% 정도 줄었다.

**묶음 나누기.** 정산이 묶음 합계로 이뤄지니까 두 묶음의 지역과 용량이 비슷하게 나눴다. 발전 패턴이 거의 똑같은 발전소 쌍은 일부러 다른 묶음에 넣었다. 한 지역 날씨를 틀렸을 때 한쪽 묶음만 크게 무너지지 않게 하려고.

**모델 9개.** 발전소별 부스팅 트리, 묶음 단위 트리 두 개, 신경망 여섯 개.

**앙상블.** 하루에 '얼마나' 나오는지와 하루 중 '언제' 나오는지를 나눠서 따로 섞었다. 하루 총량은 트리 쪽이 잘 맞혔고, 시간 패턴은 신경망 비중이 더 컸다.

**기상 모델 3종 결합.** 기상청 예보 자리에 영국 기상청 예보와 ECMWF의 AI 예보(AIFS)를 넣은 예측을 두 개 더 만들어 합쳤다. 기상청 예보 제공이 2026년 3월 말에 끝나서, 평가 기간 마지막 두 달은 이 둘이 메웠다.

**후처리.** 전체 수준을 1% 올리고, 예보 변화를 반영해 일부 날은 조금 낮췄다.

학습 기간 검증에서 잰 효과는 이 정도였다.

| 한 것 | 오차 감소 |
|---|---|
| 기상청 UM 격자 입력 (발전소별 모델) | 약 3% |
| 영국 기상청 예보 결합 | 1.5~1.8% |
| AIFS 결합 (봄 91일만 검증) | 약 1.1% |
| 전체 수준 1% 올리기 | 약 0.7% |
| 예보 변화 반영 | 0.6~0.8% |
